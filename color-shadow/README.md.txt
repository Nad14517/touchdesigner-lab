# Color Shadow Study

**Status:** Complete
**Tool:** TouchDesigner
**Type:** Procedural visuals

## Overview

An experiment exploring how procedural noise textures and displacement can be used to create an organic, animated pink smoke effect.

## Techniques

- Noise TOP for procedural texture generation
- Level TOP for brightness and contrast adjustments
- Displace TOP for texture distortion
- Lookup and Ramp TOPs for color mapping

## What I Learned

- Generating visual textures from noise.
- Using displacement maps to create organic movement.
- Adjusting color while preserving texture details.
- Understanding node-based visual programming.
