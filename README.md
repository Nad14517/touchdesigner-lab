# TouchDesigner Lab

A collection of creative coding experiments, procedural textures, and real-time visuals built with **TouchDesigner**.

This repository documents my journey into creative coding through experimentation, visual exploration, and learning by building.

## Experiments

| Project | Description | Status |
|---|---|---|
| [Color Shadow](./color-shadow/) | Procedural blue shadow using noise textures and displacement. | Completed |

## Tools & Techniques

- TouchDesigner
- Procedural noise and texture generation
- Image displacement and compositing
- Real-time image processing
- Motion detection and interactive visuals

## Repository Structure

Each experiment lives in its own folder and includes a dedicated README, project files, and visual previews when available.

## Philosophy

This is a work in progress: a space to experiment, break things, understand how they work, and turn ideas into visuals.

Not every experiment needs to become a finished project. The process is part of the work.
